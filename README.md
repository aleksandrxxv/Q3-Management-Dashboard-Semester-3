# Q3 Industrial Monitoring Dashboard

## Context

In production environments and industrial processes, it is crucial that machines remain continuously operational. Downtime can lead to high costs, loss of productivity, and inefficiency.

Although existing monitoring data provides opportunities to detect downtime early, there is currently no automated notification system to alert when machines go offline. To solve this problem, I developed a reliable, automated monitoring solution that improves operational efficiency and reduces unexpected downtime.

## Solution Overview

The application consists of two main components:

### Supabase Backend

We used **Supabase** as the database and backend. Supabase is an open-source alternative to Firebase and provides:

- Real-time database updates
- A REST API for communication
- Built-in authentication for secure user access

### Next.js Frontend

The frontend is built using **Next.js**, a React framework that enables:

- Server-Side Rendering (SSR) for performance and SEO benefits
- Static Site Generation (SSG) for optimized deployment
- A feature-rich ecosystem to build scalable and maintainable applications
